# 🌸 Chúc Mừng 20/10 — Dành Riêng Cho Thủy Tiên ✨

Một trang web kỷ niệm đặc biệt mừng ngày Phụ nữ Việt Nam 20/10 dành riêng cho Thủy Tiên, được thiết kế theo phong cách **Y2K Scrapbook & Pastel Aesthetic**.

---

## 🎀 Điểm Nổi Bật

- **Scrapbook Hero Board**: Bảng dán Polaroid, sticker bánh ngọt, washi tape, hiệu ứng gõ chữ Typewriter.
- **BGM Widget**: Phát nhạc nền *"Đủ nắng hoa sẽ nở"* (Phùng Khánh Linh) với đĩa than vinyl xoay sinh động.
- **Memory Gallery 16 Ảnh**: Bộ sưu tập 16 khung hình Polaroid với hiệu ứng góc xoay tự nhiên, dán tape vintage và hỗ trợ Lightbox phóng to khi click.
- **Special Interactive Gift Box**: Hộp quà bí mật mở ra chiếc "Voucher Đặc Quyền 20/10" với hạn sử dụng trọn đời.
- **Ambient Petal Falling**: Hiệu ứng cánh hoa và emoji nhẹ nhàng rơi trên nền Canvas.
- **Fully Responsive**: Hiển thị đẹp mắt trên cả máy tính lẫn điện thoại di động.

---

## 🚀 Cách Mở & Chạy Dự Án

Trang web thuần **HTML, CSS và JavaScript**, không cần cài đặt dependencies phức tạp.

1. Clone repository về máy:
   ```bash
   git clone https://github.com/minhchu43/ChucTien-20-10.git
   ```
2. Mở trực tiếp file `index.html` bằng trình duyệt web bất kỳ hoặc dùng Live Server.

---

## 🌐 Triển Khai GitHub Pages (Tùy Chọn)
Bạn có thể dễ dàng host trang web miễn phí lên GitHub Pages:
1. Vào mục **Settings** của repository trên GitHub.
2. Chọn **Pages** ở menu bên trái.
3. Ở phần **Branch**, chọn `main` và thư mục `/ (root)` rồi nhấn **Save**.
4. Website sẽ online sau 1–2 phút tại địa chỉ: `https://minhchu43.github.io/ChucTien-20-10/`
